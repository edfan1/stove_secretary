# Future concrete contracts

Reserved for concrete cross-application schemas once implementation choices are made. None exist yet. The [semantic contract register](../docs/contracts/register.md) is the current canonical definition of IC01–IC11; logical contracts need not become network APIs.

Future schemas should link to their semantic contract IDs and state compatibility/versioning behavior, including older installed clients. Keep provider-specific formats in adapters unless intentionally part of a shared boundary. Folder existence does not select a schema language or transport.
