# Shared development commands

Intended home for future shared capture, replay, evaluation, and documentation checks. No scripts or application commands are implemented in the repository yet. Add commands only when runnable, document prerequisites and effects, and keep application-specific startup/build details with their application.

For the bootstrap, documentation checks use a temporary dependency-free script outside the repo. Follow [CONTRIBUTING](../CONTRIBUTING.md) and the [maintenance workflow](../docs/maintenance.md); no dependency-heavy documentation toolchain is required.
